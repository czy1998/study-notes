# 介绍

Redis（Remote Dictionary Server）是开源的内存数据结构存储，常用作数据库、缓存、消息队列和流引擎。

它属于 NoSQL 里的键值存储：一个 key 对应一个带类型的 value。数据主要放在内存里读写，延迟通常是亚毫秒级；需要时可以用 RDB 快照或 AOF 日志持久化到磁盘。

常见数据类型：

| 类型       | 适合做什么             |
| ---------- | ---------------------- |
| String     | 缓存值、计数器、token  |
| Hash       | 用户信息、对象字段     |
| List       | 队列、最新动态         |
| Set        | 去重、标签             |
| Sorted Set | 排行榜、延时队列、限流 |
| Stream     | 消息流、事件日志       |
| JSON       | 嵌套对象、接口结果缓存 |

默认端口是 `6379`。

## 有什么用

Redis 适合「读得多、要很快」的场景，常见用途：

- **缓存**：把热点数据放内存，减轻 MySQL / 接口压力
- **会话**：存登录态、购物车，配合过期时间自动清理
- **排行榜**：用 Sorted Set 按分数排序
- **计数和限流**：`INCR` + 过期时间做访问计数、接口限流
- **队列 / 后台任务**：List 或 Stream 做轻量任务队列
- **实时消息**：Pub/Sub 做通知、聊天室广播

它通常不是 MySQL 的完全替代品。复杂关联查询、强事务约束仍适合关系型数据库；Redis 更常作为热数据层，和主库一起用。

## 如何使用

### 安装和启动

macOS：

```sh
brew install redis
brew services start redis
```

Docker：

```sh
docker run -d --name redis -p 6379:6379 redis
```

### 命令行

```sh
redis-cli
PING          # 返回 PONG 表示连通
```

常用命令：

```sh
SET name candy
GET name                  # candy

SETEX token 60 abc        # 60 秒后过期
EXPIRE name 10

INCR page:view            # 计数 +1

HSET user:1 name candy age 18
HGETALL user:1

LPUSH jobs task-1
RPOP jobs                 # 取出队列头部

ZADD rank 100 candy
ZREVRANGE rank 0 2 WITHSCORES

PUBLISH chat "hello"
SUBSCRIBE chat
```

查看和删除：

```sh
KEYS *          # 生产环境别用，会扫全库
SCAN 0 MATCH user:* COUNT 100
TTL name
DEL name
FLUSHDB         # 清空当前库，慎用
```

### Node.js 里用

```sh
npm install redis
```

```js
import { createClient } from "redis";

const client = createClient({
  url: "redis://127.0.0.1:6379",
});

client.on("error", (err) => console.error("Redis Error", err));

await client.connect();
await client.set("hello", "world", { EX: 60 });
const value = await client.get("hello");
console.log(value); // world
await client.quit();
```

### 使用注意

- key 自己约定前缀，例如 `user:1:session`，方便排查和批量处理
- 缓存一定要设过期时间，避免内存被写满
- 内存满了会按淘汰策略删 key（常见是 `allkeys-lru`），不是无限存
- 生产不要用 `KEYS *`，改用 `SCAN`
- 敏感数据不要明文乱放，需要密码、网络隔离和权限控制
