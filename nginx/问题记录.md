# 问题记录

## 1. h5页面，两个接口，一个正常返回 200，一个 404 找不到

**背景**

如标题所示

/api/a
/api/b

**解决办法**

于是开始排查

1. 检查后端项目，接口确实存在
2. 检查 服务器 nginx 配置，看到 /api 转发到 8181 端口
3. `ss -lntp | grep 8181` 检查 8181 是哪个服务在监听，知道是 java
   ```
   LISTEN 0      100                *:8181             *:*    users:(("java",pid=33544,fd=380))
   ```
4. 通过 进程id 得知其启动时的命令 `ps -p 33544 -o pid,user,lstart,cmd --width 1000` ，得知接口走的是 api，而 另一个接口是 check 中的
5. 去测试环境检查接口 nginx 配置，得知其走的的是 gateway 网关，于是想把预发布也改成 走网关
6. `ps -ef | grep hera-gateway | grep -v grep` 查询网关进程，排除 grep，得知 网管已经启动 pid 为 26843
7. `ss -lntp | grep "pid=26843"` 通过 pid 查询监听端口，得知是 19999
8. 修改预发布配置文件端口为 19999，重启 nginx 后，页面回复正常

**注意要点**

```sh
# 会去掉 /api

location /api/ {
    proxy_pass http://localhost:8182/;
}

# /api/qqq/www → http://localhost:8182/qqq/www

# 不写路径，整段 URI 原样带过去

location /api/ {
    proxy_pass http://localhost:8182;
}

# /api/qqq/www → http://localhost:8182/api/qqq/www
```
